# 三線 練習帳 — 本調子 工工四トレーナー

三線（さんしん）初心者のための Web 練習アプリです。単一の `index.html` だけで動作し、
ビルド・外部音声ファイル・外部ライブラリを一切必要としません。

## 特長

- **棹（さお）ビジュアル** — 男弦・中弦・女弦の 3 本と、各弦 4 つの勘所をタップして発音
- **合成音** — Web Audio API のオシレーター＋エンベロープで、撥（バチ）のアタック感がある撥弦音を生成
- **工工四（くんくんしー）** — 伝統的な縦書き・右から左のレイアウト（横書きにも切替可）
- **模範演奏** — 再生に合わせて棹の勘所と工工四のマスがリアルタイムでハイライト
- **レスポンシブ** — スマートフォン／PC 両対応、ダブルタップズーム抑止（`touch-action: manipulation`）

## 調弦（本調子 C - F - C）

| 弦 | 開放 | 勘所と基準周波数 |
| --- | --- | --- |
| 男弦（ウーヂル） | C3 | 合 130.81 / 乙 146.83 / 老 164.81 / 下老 174.61 Hz |
| 中弦（ナカヂル） | F3 | 四 174.61 / 上 196.00 / 中 220.00 / 尺 246.94 Hz |
| 女弦（ミーヂル） | C4 | 工 261.63 / 五 293.66 / 六 329.63 / 七 349.23 Hz |

## 収録曲

| 曲 | 構成 | 備考 |
| --- | --- | --- |
| チューリップ | 12 小節 / 48 マス | 中弦「四」(F3) を “ド” として移調した入門アレンジ |
| 安里屋ユンタ（冒頭） | 8 小節 / 32 マス | 琉球音階による**練習用の簡易アレンジ**。正規の工工四とは異なります |
| 基礎練習：合〜七の音階 | 7 小節 / 28 マス | 12 の勘所を上行・下行 |

譜面は `index.html` 内の `SONGS` 配列にあり、`kk`（工工四）と `ly`（歌詞）の文字列を
差し替えるだけで曲を追加・変更できます。`|` が小節区切り、`○` が休みです。

## 使い方

`index.html` をブラウザで開くだけです。ローカルで確認する場合:

```sh
python -m http.server 8000
# → http://localhost:8000
```

音が出ない場合は、端末のマナーモードを解除し、画面を一度タップしてください
（ブラウザの自動再生制限を解除します）。

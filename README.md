# 三線 練習帳 — 本調子 工工四トレーナー

三線（さんしん）初心者のための Web 練習アプリです。`index.html` をブラウザで開くだけで動作し、
ビルド・外部音声ファイル・外部ライブラリを一切必要としません。
http(s) で配信した場合だけ `manifest.webmanifest` と `sw.js` が加わり、オフラインでも開けます。

## 特長

- **棹（さお）ビジュアル** — 男弦・中弦・女弦の 3 本と、各弦 4 つの勘所をタップして発音
- **合成音** — Web Audio API のオシレーター＋エンベロープで、撥（バチ）のアタック感がある撥弦音を生成
- **工工四（くんくんしー）** — 伝統的な縦書き・右から左のレイアウト（横書きにも切替可）
- **模範演奏** — 再生に合わせて棹の勘所と工工四のマスがリアルタイムでハイライト
- **練習支援** — 区間リピート、カウントイン、メトロノーム、段階的な速度練習、設定と進捗の保存
- **演奏問題** — 次に弾く工工四だけを出題。正しい勘所を押せば次へ、間違えれば正解を教えます
- **調弦支援** — 開放弦の基準音を持続音で鳴らし、実際の弦との「うなり」で合わせられます
- **譜面の追加** — 自分の工工四を JSON で読み込み・書き出しできます
- **レスポンシブ** — スマートフォン／PC 両対応、ダブルタップズーム抑止（`touch-action: manipulation`）

## 収録曲

| 曲 | 構成 | 備考 |
| --- | --- | --- |
| てぃんさぐぬ花 | 12 小節 / 48 マス | 沖縄を代表する民謡（作詞・作曲とも不詳）。琉球音階による**練習用の簡易アレンジ**で、流派の正規の工工四とは異なります |
| 安里屋ユンタ（冒頭） | 8 小節 / 32 マス | 琉球音階による**練習用の簡易アレンジ**。正規の工工四とは異なります |
| 基礎練習：合〜七の音階 | 7 小節 / 28 マス | 12 の勘所を上行・下行。最初はこの曲から |

譜面は `index.html` 内の `SONGS` 配列にあり、`kk`（工工四）と `ly`（歌詞）の文字列を
差し替えるだけで曲を追加・変更できます。`|` が小節区切り、`○` が休みです。

収録しているのはいずれも著作権の切れた伝承曲（沖縄・八重山の民謡）と、自作の基礎練習です。
曲を追加するときは、旋律と歌詞の両方の権利状態を確認してください。

### 曲データの検証

`SONGS` の読み込み時に次を検証し、問題があれば `console.warn` へ出します。
表示自体は止めず、未定義の記号は従来どおり休みとして描画します。

- 未定義の工工四記号
- 小節ごとの拍数が `beats` と一致するか
- 工工四と歌詞の小節数・セル数が一致するか
- 曲 ID の重複
- 勘所の周波数が正の数か

`index.html?debug=1` で開くと、同じ内容を画面下部にも一覧表示します。

## 練習機能

### 区間リピート

譜面の上の「練習範囲」で、繰り返したい小節を選びます。

- 「第 □ 小節から / まで」— 指定した範囲だけをループします。範囲外の小節は薄く表示されます
- 「◀ 前の小節 / 次の小節 ▶」— 再生開始位置を 1 小節ずつ動かします
- **マスをタップ** すると、その音を確認しつつ開始位置がそこに移ります
- **小節番号を押す** と、その小節の先頭からになります

再生中に位置を変えると、予約済みの音を破棄してその場でジャンプします。

### カウントインとメトロノーム

- **カウントイン**（既定で入）— 再生前に 1 小節分のクリックを入れます
- **メトロノーム** — 模範演奏にクリックを重ねます
- **♪ メトロノーム単体** — クリックだけを鳴らします

拍頭は高い音（1760 Hz）で強調します。拍数は曲データの `beats` に従います。

### 段階的な速度練習

- **速度プリセット** — ゆっくり 60 / 標準 80 / 仕上げ 110 BPM
- **ループごとに +4** — 練習範囲を 1 周するたびに BPM を 4 上げます（スライダーの上限 160 で止まります）

テンポ変更はいずれも**次に予約される拍から**反映されます。

### 設定と進捗の保存

`localStorage`（キー `sanshin-trainer/v1`）に保存し、次回開いたときに復元します。

| 全体 | 曲ごと |
| --- | --- |
| 最後に選んだ曲 / BPM / 音量 / 縦書き・横書き / くり返し / カウントイン / メトロノーム / 自動上昇 | 練習範囲 / 最後に練習した位置 / 練習回数 / 最高 BPM |

練習回数と最高 BPM は、練習範囲を 1 周した時点で記録し、譜面の見出しに表示します。
プライベートウィンドウなどで `localStorage` が使えない場合も、保存を諦めて通常どおり動作します。

## 演奏問題モード

工工四の見出しにある「演奏問題」ボタンで切り替えます。

- **次に弾く工工四だけ**が大きく表示されます。弦も指も出ないので、勘所を思い出す練習になります
- 棹の正しい勘所を押すと次へ進みます。間違えると、正しい勘所が棹の上で光り、弦と指が表示されます
- 正答率と連続正解数（曲ごとの最高記録つき）が出ます

出題は**練習範囲から**、休みを除いた順番です。つまり

- 練習範囲を数小節に絞れば、**そのフレーズだけ**の出題になります
- 「基礎練習：合〜七の音階」を選べば、**音階からの出題**になります

模範演奏やメトロノームを始めると、問題モードは自動的に終了します。

## 調弦支援

棹の下にある「調弦支援」で、開放弦の基準音を鳴らせます。

| ボタン | 音 |
| --- | --- |
| 男弦 | C3 130.81 Hz |
| 中弦 | F3 174.61 Hz |
| 女弦 | C4 261.63 Hz |

- もう一度押すと止まります。「止める」で全部止まります
- **複数の弦を同時に鳴らせます**（オクターブや 4 度の確認に使えます）
- ピッチを一切揺らさない持続音なので、実際の弦と同時に鳴らして「ワワワ」といううなりが
  消えるまで糸巻を回せば合います
- 模範演奏の停止では止まりません（別系統で鳴らしています）

撥弦音の `pluck()` は最長 2 秒で減衰しきる設計なので、調弦音には専用の合成パスを使っています。
マイク入力によるチューナーは未実装です。

## 譜面の追加・書き出し（JSON）

工工四の下にある「譜面の追加・書き出し（JSON）」を開きます。

```json
{
  "format": "sanshin-trainer/songs",
  "version": 1,
  "songs": [
    {
      "id": "my-song",
      "title": "曲名",
      "note": "補足（任意）",
      "beats": 4,
      "kk": "合 乙 老 下老 | 四 上 中 尺",
      "ly": "あ い う え | か き く け"
    }
  ]
}
```

- 単体の曲オブジェクトや、曲の配列でも読み込めます
- 貼り付けて「読み込む」か、「ファイルから…」で JSON ファイルを選びます
- **収録曲と同じ検証をかけ、1 件でも問題があれば 1 曲も追加しません。**
  何が悪いかは一覧で表示されます
- 収録曲と同じ `id` は使えません。追加済みの譜面と同じ `id` は置き換えになります
- 「この曲を書き出す」「全曲を書き出す」で JSON を取り出せます（上の入力欄にも入ります）
- 追加した譜面は**このブラウザの `localStorage` にだけ**保存されます。
  他の端末やブラウザには共有されないので、残したいものは書き出しておいてください

外部データは `id` / `title` / `note` / `beats` / `kk` / `ly` の 6 つだけを取り出し、
表示はすべて `textContent` を通します。HTML 文字列の組み立てはアプリ内に一切ありません。

## オフラインで使う（PWA）

`index.html` 単体でも（`file://` で直接開いても）これまでどおり全機能が動きます。
**http(s) で配信したときだけ** Service Worker が登録され、次のことができます。

- オフラインで開ける
- ホーム画面／デスクトップにインストールできる

```sh
python -m http.server 8000
# → http://localhost:8000
```

キャッシュはネットワーク優先で、取得に失敗したときだけ使います（更新を取りこぼさないため）。
`sw.js` の `CACHE` を変えると、古いキャッシュは破棄されます。

## ファイル構成

| ファイル | 役割 | 必須 |
| --- | --- | --- |
| `index.html` | アプリ本体。HTML・CSS・JS がすべて入っています | はい |
| `manifest.webmanifest` | PWA のメタデータとアイコン（SVG の data URI） | いいえ |
| `sw.js` | オフライン用の Service Worker | いいえ |

## 使い方

`index.html` をブラウザで開くだけです。ローカルで確認する場合:

```sh
python -m http.server 8000
# → http://localhost:8000
```

音が出ない場合は、端末のマナーモードを解除し、画面を一度タップしてください
（ブラウザの自動再生制限を解除します）。

## 再生の振る舞いとアクセシビリティ

- **停止** — 再生セッションごとの `GainNode` を 0.12 秒でフェードさせるため、
  先読みで予約済みの音が停止後に鳴り残りません。手弾きの音は停止の影響を受けません
- **テンポ変更** — 再生中に BPM を変えると、**次に予約される拍から**反映されます
  （すでに鳴っている音の長さは変わりません）
- **拍ドット** — 曲の `beats` に合わせて生成します（4 拍固定ではありません）
- **reduced motion** — OS の「視差効果を減らす／アニメーションを減らす」設定
  （`prefers-reduced-motion: reduce`）を尊重し、譜面のスムーズスクロールと
  発光・トランジションを抑制します（選択中の輪郭は残ります）
- **キーボード** — Space で再生／停止。勘所・譜面のマス・小節番号は Tab と Enter／Space で操作できます。
  縦書き／横書きの切替や曲の変更で譜面を作り直しても、フォーカスは同じマスに戻ります
- **状態通知** — 手弾きの現在音や、練習範囲・テンポの変更を `aria-live="polite"` で通知します。
  **模範演奏中は毎拍読み上げません**（開始・停止・自動上昇のときだけ）
